# 코드 보안·효율 검토 결과

검토일: 2026-11-26. 기준: 159902f 이후 변경.

Python 로컬 API, Cloudflare Worker·법령 어댑터·웹 검색, 화면의 API 통신·문서 편집·내보내기 경로, 정적 파일 허용 목록, 의존성 목록을 검토했습니다. 외부 API 키와 실제 개인정보를 이용한 운영 침투 시험은 수행하지 않았습니다.

## 수정한 보안 항목

| 항목 | 확인한 문제와 조치 |
| --- | --- |
| Python 외부 API 리다이렉트 | urllib 기본 동작이 다른 주소로 이동하면서 Authorization 등의 헤더를 전달할 수 있었습니다. 자동 리다이렉트를 차단하고 3xx에는 고정된 오류 안내를 반환합니다. 외부 오류 응답도 닫습니다. Workers의 기존 리다이렉트 차단은 유지합니다. |
| 로컬 서버 Host 검증 | 루프백에 연결된 요청이라도 임의 도메인의 Host를 허용했습니다. 로컬 바인딩에서는 localhost·127.0.0.1·루프백 IPv6 및 실제 서버 포트만 허용해 DNS 재바인딩 경로를 줄였습니다. 잘못된 Origin 형식도 안전하게 거부합니다. |
| 느린 요청 | POST 본문에 200초를 기다렸고 요청 헤더에는 명시적인 소켓 대기 제한이 없었습니다. 연결 읽기 제한을 15초로 설정하고 본문 시간 초과 시 408을 반환하며 API 처리 슬롯을 반환합니다. 외부 AI 검색의 90초·법령 API의 30초 제한과는 다른 소켓 입력 제한입니다. |
| 검토 토큰 검증 | Workers의 HMAC 문자열 직접 비교를 Web Crypto의 서명 검증으로 바꿨습니다. 기존 유효 기간·항목·근거 지문 검증은 유지합니다. |
| 로그 | 임의 /api/ 요청 경로가 그대로 로그에 들어가던 부분을 고정된 알려진 경로 또는 /api/unknown으로 제한했습니다. 요청 본문·키·외부 오류 원문은 기록하지 않습니다. |

## 줄인 불필요한 처리

- 같은 법령·조·항·호·처리 유형·근거 코드·버전의 중복 후보는 한 번만 검증합니다. 동일 근거가 반복되어 유료 AI 검토가 반복되는 것을 방지합니다. 서로 다른 조항과 처리 근거는 유지합니다.
- 상태 조회는 30초간 재사용하고 동시에 들어온 조회를 하나로 합칩니다. 초기 CSRF 쿠키 발급 경쟁도 줄입니다. 서버 재시작 등으로 실행 전에 CSRF 검사가 거부한 경우에만 상태를 새로 조회하고 한 번 재전송합니다. 비용이 발생할 수 있는 5xx 응답이나 네트워크 단절을 화면에서 자동 재전송하지 않습니다.
- AI 검토 입력에서 화면용 paragraphSegments, 검증 시각 등의 메타데이터를 제거합니다. 선택한 본문과 적용 조건을 담은 전체 조문, 연결 근거는 유지합니다. 전체 조문이 선택 본문과 동일할 때만 중복 필드를 생략합니다.
- 검색 과정에서 사용하지 않는 적용용 서명 토큰을 발급하지 않습니다. 별도의 적용 전 AI 검토에는 기존 토큰을 발급합니다.
- 화면에서 사용하지 않는 웹 검색 발췌·출처 목록을 API 응답에서 제거했습니다. 검색 근거 자료는 서버의 후보 생성 단계에 계속 사용합니다.

## 유지한 보호와 운영상 남은 사항

정적 파일 허용 목록, .env·서버 소스 접근 차단, JSON 요청·크기 제한, 동일 출처 검사, XML DTD·외부 엔터티 거부, HTML 텍스트 이스케이프, 법령 원문 검증, CSRF 및 요청 횟수 제한을 유지했습니다.

운영 Worker의 AI API에는 현재 로그인이나 기관별 접근 제어가 없습니다. 공개 방문자도 IP별 요청 한도 안에서 유료 호출을 실행할 수 있고, IP별 한도는 전체 비용 상한이 아닙니다. OpenRouter 키의 지출 한도를 설정하고 비공개 운영이 필요하면 Cloudflare Access 등의 접근 제어를 적용해야 합니다. 이번 수정으로 새로운 로그인 절차를 추가하지는 않았습니다.

Python 서버는 기본적으로 로컬 컴퓨터용입니다. HOST=0.0.0.0으로 외부에 열 때는 인증·TLS·앞단 요청 제한을 별도로 마련해야 합니다. 개인정보 검출 정규식은 명백한 식별값을 차단하는 보조 수단이므로 실제 개인정보 대신 항목명·업무 목적만 입력해야 합니다.
