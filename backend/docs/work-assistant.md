# 업무 설명으로 시작하는 작성 경로

홈의 업무 설명 입력 → 수집·이용 대화 → 목적 외 이용·제3자 제공 확인 → 4단계 문서 작성 순서입니다. 원래 ‘동의서 생성’·‘빠른 생성’ 버튼은 기존 1~4단계를 사용합니다.

대화와 초안은 서버 DB에 저장하지 않습니다. 같은 탭의 sessionStorage에 마지막 사용 후 최대 24시간 보관해 새로고침 뒤에도 복구합니다. 대화 지우기를 누르면 즉시 삭제합니다. 다른 브라우저나 기기로 자동 동기화하지 않습니다. 브라우저 저장이 차단된 경우에는 현재 화면에서만 유지되며 화면에 안내합니다. 업무 설명·항목명·기관명은 AI 요청에 사용됩니다. 실제 개인의 식별값을 입력하지 않습니다.

## 자동 작성 범위

- 서버는 공식 자료를 검색하고 현행 법령 전문에서 업무 근거·기재사항·법정 보존기간 후보를 찾습니다.
- AI가 제안한 항목·기간은 실제 원문의 연속 발췌에 있는지 검사합니다. 기간은 해당 주체·서류에 맞는지 다시 검토합니다. 근거별 항목 적용 가능성도 검토합니다.
- 원문으로 확인되지 않은 항목·기간을 관행이나 모델 기억으로 채우지 않습니다. 추가 항목·기간은 질문하거나 선택 입력으로 받습니다. 미확인 상태로 계속한 내용은 4단계에서 수정할 수 있으며, 필수 내용이 비어 있으면 완성되지 않습니다.
- 주민등록번호는 일반 처리 근거와 구체적 주민등록번호 허용 근거가 모두 확인된 항목만 자동 입력합니다. 이 검사만으로 모든 사실관계에 대한 법률 판단을 보증하지 않습니다.
- 목적 외 이용·제공이 있으면 업무와 제공받는 기관 등을 별도로 묻습니다. 마지막에 1~3단계 상태와 확인된 근거를 채우고 4단계로 이동합니다. 이전 단계로 돌아가 검토할 수 있습니다.

`POST /api/work/plan`은 상태를 서버에 보관하지 않습니다. 후속 답변에서는 24시간 유효한 대화 전용 서명으로 조문 참조와 이전 확인 내용을 검증해 최초 검색을 재사용하고, 공식 원문과 적용 가능성을 다시 확인합니다. 서명은 업무·처리 유형·참조 목록·이전에 확인한 항목과 기간에 묶입니다. CSRF·같은 출처 검사·AI 요청 한도는 기존 API와 동일하며 요청 크기는 이 경로만 96KiB로 제한합니다. 대화는 최근 10개, 개별 메시지는 1,500자, 항목은 30개, 원문 참조는 8개까지입니다.

## 문서 기본 문구

4단계 상단에서 기관명을 확인·수정합니다. 제목은 간단한 목적을 사용하고 제목·안내문은 자동 적용합니다. 직접 수정한 값은 단계 이동 시 덮어쓰지 않습니다. 필수 거부 안내는 ‘서비스를 받을 수 없습니다.’, 선택은 ‘동의를 거부해도 불이익이 없습니다.’를 기본 적용합니다. 선택 거부 안내를 수정하면 ‘동의를 거부할 경우 (입력한 내용)’으로 표시합니다.

## 폴더

- `backend/`: Python 서버, Cloudflare Worker, 법령·대화 처리와 공통 근거 규칙
- `frontend/`: 화면·대화 상태와 문서/PDF/HWPX 생성
- `design/`: CSS, 출력 자산 및 빠른 생성 설정
- 루트 `server.py`: 기존 실행 명령을 유지하는 진입점

빠른 생성의 원본 값은 `design/quick-templates.json`입니다. 빌드와 로컬 서버가 같은 JSON에서 `/quick-templates.js`를 제공합니다. 설정을 바꾼 뒤 운영에는 `npm run deploy`로 반영합니다.

## 검증

`node --test backend/tests/work-assistant.test.mjs`, `python -m unittest discover -s backend/tests -p test_work_assistant.py`, 실행 중인 서버를 대상으로 `node frontend/tests/work-chat.cjs`를 사용합니다. 브라우저 회귀 검사는 합성 API 응답을 사용하며 실제 모델 정확도 검증과 구분합니다.


## 대기·재확인·시작 전 편집

확인 중에는 점 애니메이션과 입력·전송 잠금 안내를 표시합니다. 움직임 줄이기 설정에서는 애니메이션을 끕니다. 질문은 주제별 굵은 제목과 문단으로 나눕니다. 주민등록번호 허용 근거는 별도 구역에서 일반 처리 근거와 구분해 확인합니다.

일시 조회 실패 때는 기존 항목·기간·법령을 재확인 대상으로 보관합니다. 과거 결과를 현재 검증 완료로 간주하지 않으며 재확인 전에는 자동 적용하지 않습니다. 빈 조문 참조는 새 검색으로 복구하고, 명시적인 재검색도 기존 서명된 내용을 버리지 않습니다. 대화 전용 서명만 24시간이며 일반 법령 적용용 AI 검토 서명의 5분 제한은 바꾸지 않습니다.

빠른 생성 시작 전에 제목·목적·항목·기간을 수정할 수 있습니다. 안내문은 원본을 유지하는 읽기 전용입니다. 제공된 XLSX를 기준으로 8개 양식의 값을 갱신했고 원본 안내문은 유지했습니다.
