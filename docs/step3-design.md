# 3단계 디자인 변경과 확인 범위

`design-taste:design-taste-frontend` 지침 중 정보 위계·간격·버튼 크기·접근성·실제 화면 검증을 적용했습니다. 업무 입력 화면의 특성에 맞춰 기존 파랑·남색·회색 팔레트와 글꼴을 유지했습니다. 마케팅용 전체 화면 섹션이나 새 라이브러리는 추가하지 않았습니다.

## 비교 조사: 실제 사이트 접근 제한

국가법령정보센터, 개인정보포털, 개인정보보호위원회, 정부24, 찾기쉬운생활법령, 종합법률정보, 전자소송포털, 국민신문고, 국민건강보험, KRDS의 10개 사이트 접속을 시도했으나 이 환경의 외부 호스트 접근 제한으로 화면을 열지 못했습니다. **10개 실제 사이트를 시각적으로 확인했다는 의미가 아닙니다.** 대신 접근 가능한 다음 공공 서비스 디자인 자료 10개를 조사했습니다.

|---|---|---|

README만 확인한 자료는 실제 화면이나 상세 컴포넌트 검토로 간주하지 않습니다. 스킬에 포함된 전용 검사 실행기는 작업 파일에 없어 실행하지 않았으며, 아래 프로젝트 브라우저 검증으로 확인했습니다.

## 반영한 디자인

- 대분류 24px, 작업 제목 20px, 본문 16px, 보조 정보 13px로 구분합니다. ‘개인정보 유형’은 데스크톱 24px·모바일 23px입니다.
- 제목과 설명 사이를 줄이고 관련 단계는 20px 간격으로 묶었습니다. 버튼은 내용 너비를 따르며 최소 높이는 44px입니다. 직접 추가한 법령의 AI 검토는 보조 버튼, 적용은 주 버튼입니다. AI 검색 결과에는 추가 AI 검토를 표시하지 않습니다.
- ‘검토할 법령’을 부모 펼침 영역으로 두고 개별 법령을 들여 쓴 하위 영역으로 구성했습니다. 펼침 기호는 + / −입니다. 선택 안함은 법령 데이터를 삭제하지 않고 현재 목록에서 숨기며(기존 적용은 해제), 부모 영역을 다시 펼치면 복원됩니다.
- 검색 전에는 결과 상자를 표시하지 않습니다. 5건 이상일 때 데스크톱은 64px 행 5개와 상태 줄로 362px, 모바일은 72px 행 5개와 상태 줄로 402px입니다. 추가 로딩 중에는 상자와 아래 콘텐츠의 위치를 유지합니다. 5건 미만은 실제 행 수만 사용합니다.
- 하나를 선택하면 같은 유형의 미선택 법령은 숨기고 ‘다른 법령 보기’로 복원합니다. 검색된 개인정보 보호법은 조·항·호 제목 아래 ‘전문 보기’를 배치하고 중복 인용과 유형별 조항 안내를 제거했습니다.
- 전체 선택은 일부 선택 시 중간 상태를 표시합니다. 수집 목적은 대분류 아래에만 작게 표시합니다.
- 정당한 이익의 입증 책임은 빨간색 경고로 표시합니다. AI 검토 중에는 회전 표시를 제공하며 움직임 줄이기 설정에서는 회전하지 않습니다.
- 모델·서비스명·검토 시각을 일반 화면에서 제거했습니다. 연결 설정과 API 운영 정보는 별도 운영 문서에서 안내합니다.

## 검증

합성 API 응답으로 1440px·768px·390px와 200% 확대에서 확인했습니다. 법령 숨김·복원·재검색 보존, 5행 표시, 지연 로딩 중 위치 유지, 항·호·목 표시, 원문 항 전체, 경고, 전체 선택, 직접 추가한 법령의 선택적 AI 검토, 부정적인 AI 의견 후 적용, AI 검색 결과에서 추가 AI 호출 없이 적용, 단일 결과 높이, PDF·HWPX 출력을 검사합니다. 실제 외부 API 인증·모델의 정확도·응답 속도는 별도 검증이 필요합니다.
