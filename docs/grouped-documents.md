# 동의와 고지 분리 및 공통 내용 통합

4단계 미리보기·쪽 미리보기·최종본·PDF·HWPX에 동일한 문서 구성을 적용합니다.

- 동의는 일반 개인정보(필수/선택), 민감정보, 고유식별정보 및 처리 유형별로 구분합니다. 같은 구분의 공통 셀은 병합하되 동의·미동의 선택란은 각각 유지합니다.
- 고지는 동의 표에 섞지 않고 서명란 아래의 **고지사항 · 별도 동의가 필요하지 않은 처리**에 모읍니다. 동일한 실제 법령 근거·목적·기간·제공받는 자를 공유하면 개인정보 유형이 달라도 한 행에 표시합니다. 조건이 다르면 행을 분리합니다.
- 일반 개인정보 항목명은 강조하지 않습니다. 고지 표에서는 민감정보·고유식별정보 항목명을 강조합니다. 동의 표에서는 안내서가 정한 중요 내용도 강조합니다.
- 문서는 기본적으로 읽기 전용입니다. **표 내용 직접 수정**을 누르면 편집할 수 있고 **저장하기**로 편집을 끝냅니다. 병합된 목적·기간의 편집은 해당 공통 셀에 포함된 항목에 반영합니다.
- 완성하기는 상단과 공통 하단 이동 버튼 영역에 표시합니다. 고지 전용 문서는 고지 제목·안내문 후보를 제공하고 동의 거부 관련 입력란을 해당사항 없음으로 표시합니다.
- 파일명은 문서 제목으로 만듭니다. 운영체제에서 사용할 수 없는 문자는 치환합니다.

## 한글 파일

중요 내용의 파란색을 `#2154C7`로 통일하고 일반 항목과 중요 내용을 셀 안에서도 구분합니다. 본문 표 테두리는 검정 실선 0.12mm이며, 동의 선택란은 기존 요청대로 테두리 없는 2열 표입니다. 제목·안내문·각 항목 사이에 빈 문단을 둡니다. 동의 질문 앞에는 ☞, 서명란에는 정보주체: / 법정대리인:을 표시합니다. 법정대리인 블록 앞에 빈 문단을 두고 아동과의 관계 입력선은 흰색 마침표와 밑줄로 유지합니다.

## 검증

Playwright와 Chromium이 설치된 환경에서 시연 허용 서버를 실행합니다.

```sh
HOST=0.0.0.0 PORT=3011 LAW_SEARCH_DEMO=true python server.py
```

다른 터미널에서:

```sh
TEST_BASE_URL=http://127.0.0.1:3011 node tests/document-groups.cjs
TEST_BASE_URL=http://127.0.0.1:3011 node tests/guideline-flow.cjs
python tests/check_exports.py
python tests/check_guideline_exports.py
```

브라우저 API 응답은 합성 데이터입니다. PDF 텍스트 검증에는 pdftotext, 글자별 스타일 검증에는 선택적으로 PyMuPDF가 필요합니다. 한글은 XML 구조를 확인하며 실제 한글 프로그램의 화면 렌더링은 확인하지 않았습니다. 실제 API 인증과 모델 판단은 별도 검증해야 합니다.

기존 `.env`를 새 폴더의 `server.py` 옆에 두고 서버를 재시작한 뒤 Ctrl+F5로 새로고침하세요. `/api/status`의 `apiVersion`은 **8**입니다.
