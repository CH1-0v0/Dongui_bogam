# 수정 가능한 AI 초안

업무 대화에서 원문으로 확정하지 못한 항목·보유기간도 AI가 최소 초안으로 제안한다. 공식 원문으로 확인한 `items`·`period`와 별도로 `suggestedItems`·`suggestedPeriod`·`suggestionReason`을 반환하며, 제안값은 검증된 사실의 서명이나 법적 근거 적용 목록에 포함하지 않는다.

화면은 확인된 값이 없는 부분에 제안값을 채우고 ‘AI 초안 · 확인 필요’로 표시한다. 사용자가 항목과 기간을 바로 수정한 뒤 문서 작성 단계로 이동할 수 있다. 원문으로 확인된 기간이 있으면 초안 기간으로 덮어쓰지 않는다. 기관명·제공받는 기관명은 추측하지 않으며, 주민등록번호를 추정 초안으로 추가하지 않는다. 기존 별도 처리 근거 검증은 유지한다.

챗봇 상단에는 ‘AI는 틀릴 수 있습니다. 자동 입력된 항목·보유기간·법적 근거를 확인하고 수정해 주세요.’ 안내를 항상 표시한다. 최종 단계의 자동 작성 내용 수정란에도 초안 포함 여부를 표시한다. 이 안내는 대화·편집 UI에 표시하며 동의서 원문에 AI 문구를 추가하지 않는다.

검증: Worker 97건·Python 84건, 초안 입력·수정·문서 전달 브라우저 시험, 기존 업무 대화 브라우저 시험, Cloudflare 배포 빌드 검사를 통과했다. 실제 AI 모델의 제안값은 업무 설명과 확인된 자료에 따라 달라진다.
