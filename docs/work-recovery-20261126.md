# 대화 복구·질문 표시·빠른 생성 갱신 검증

## 원인 및 처리

이전 대화는 메모리에만 있었고 새로고침하면 사라졌습니다. 후속 조회 참조는 5분 서명이었으며, 오류 후 참조를 버리는 재시도와 빈 참조를 계속 재사용하는 경로가 있었습니다. 공식 원문 조회가 실패하면 이전 발췌가 현재 원문으로 검증되지 않아 결과에서 빠질 수 있었습니다.

이제 대화는 서버 DB 없이 같은 탭의 sessionStorage에서 마지막 활동 후 24시간 복구합니다. 새로고침 자체는 보관 시간을 무한 연장하지 않습니다. 복구 시 기존 항목·기간·법령을 보여주되 현재 적용 전에는 다시 확인합니다. 조회 중 끊긴 요청은 자동 과금 재요청 없이 사용자가 재시도할 수 있게 합니다. 대화 지우기로 로컬 자료를 삭제합니다. 저장소가 차단된 경우 메모리만 사용하고 화면에서 알립니다. 업데이트 전에 저장되지 않고 사라진 대화는 소급 복원하지 못합니다.

대화 전용 체크포인트는 별도 서명 영역에서 24시간 유효합니다. 일반 법령 적용의 AI 검토 서명은 기존 5분을 유지합니다. 이전 대화용 5분 서명은 생성 후 하루 범위에서 검증·갱신할 수 있습니다. 원문과 항목 적용 가능성은 요청마다 다시 확인합니다. 일시 실패·원문 변경·허용 요건 부족으로 현재 검증하지 못한 기존 항목·기간은 재확인 대상으로 보관하며 자동 적용하지 않습니다. 빈 참조와 검증에 실패한 참조만 있는 응답은 다음 탐색을 막는 캐시가 되지 않습니다. 명시적 재검색도 기존 확인 정보를 지우지 않습니다.

## 화면 및 설정

- 점 애니메이션과 입력·전송 잠금 사유를 표시하고 움직임 줄이기 설정을 따릅니다.
- 질문은 주제별 제목·문단으로 나누고 강조합니다. Markdown의 굵은 글씨는 HTML을 이스케이프한 후 제한적으로 표시합니다.
- 주민등록번호 허용 근거는 별도 확인합니다. 관련 법률·대통령령 원문이 번호 처리를 명시하면 별도 연결 근거를 검증하고 업무 적용 가능성을 판단합니다. 확인용 질문이 번호 수집항목을 자동 추가하지는 않습니다.
- 원문 확인 조문, 자동 적용 후보, 과거 확인·재확인 대상의 개수를 구분합니다.
- 제공된 XLSX의 8개 양식에서 제목·목적·기간·항목을 반영했습니다. 안내문은 기존 JSON과 모두 동일한 것을 확인했습니다. 시작 전에는 제목·목적·항목·기간만 수정 가능하고 안내문은 읽기 전용입니다.

## 검증 결과

Worker·대화 단위 검사 79개, Python 77개, 규칙·상태·요약 단위 검사 21개가 통과했습니다. 브라우저 검사는 로딩 잠금·질문 강조·실패 후 유지·새로고침 복구·24시간 만료·재검색 시 참조 유지·빠른 생성 편집·안내문 불변을 확인합니다. 기존 작성·분류·고지 전용 서식·PDF/HWPX 흐름도 회귀 검사합니다.

실제 운영 API에서도 주민등록번호 허용 근거를 함께 요청했습니다. HTTP 200, 약 141초에 응답했으나 의료법·시행령·시행규칙 원문 서비스가 모두 일시 조회 실패여서 처리 근거는 ‘조회 재시도 필요’로 반환됐습니다. 대화 참조 유효기간 24시간은 확인했습니다. 이 호출에서 주민등록번호 처리가 허용된다고 판정한 것은 아닙니다. 실제 허용 판정의 성공을 이번 외부 서비스 장애 상태에서 보증하지 않습니다. 조회 장애 때 이전 결과를 지우지 않는 복구 처리는 합성 장애·서명·시간 경과 검사로 확인했습니다.


이후 의료법 제22조 직접 조회는 HTTP 200으로 정상 응답했습니다. 앞서 0건이었던 대화 체크포인트를 그대로 보내 명시적 초기화 없이 후속 답변을 요청한 시험은 HTTP 200, 57초에 항목 8개와 원문 조문 4개를 반환했습니다. 의료법 제22조·의료법 시행규칙 제14조/제15조·의료법 시행령 제42조의2 제3호의6을 확인했습니다. 주민등록번호 허용 근거는 해당 시행령 조문을 표시하되 불가피성과 일반 수집 근거를 needs_information으로 남겼습니다. 보유기간은 확정되지 않아 임의로 채우지 않았습니다. 이 결과는 빈 참조를 영구 재사용하는 문제의 복구를 실제 호출로 확인한 것이며, 모든 항목의 수집 적법성이 확정됐다는 뜻은 아닙니다.

배포 사이트에서도 합성 장애를 이용한 브라우저 복구·잠금·편집 검사가 통과했습니다. 최종 배포 버전은 7e7e1c57-82fc-43b3-a179-df1ca6452f4a입니다.
