# 입력·분류·법령·문서 화면 정리

## 1단계

항목 선택창은 최대 180px 높이 안에서 스크롤합니다. 화면 아래쪽에서는 위로 열어 선택창이 화면을 벗어나지 않게 합니다. 직접 입력을 선택하면 작은 선택 칸과 텍스트 입력 칸을 같은 줄에 배치합니다. 분류 표시는 입력 칸의 시작보다 조금 안쪽에 표시합니다.

항목 앞 손잡이를 드래그해 순서를 바꿀 수 있습니다. 필수 항목이 먼저, 선택 항목이 나중에 표시됩니다. 필수 여부를 바꾸면 필수의 마지막·선택의 첫 번째가 만나는 경계로 이동합니다. 드래그로 순서를 바꿔도 필수·선택 순서를 유지합니다. 손잡이에 키보드 포커스를 두고 위·아래 화살표로 이동할 수도 있습니다.

직접 입력한 항목만 추가 API 분류 대상으로 삼습니다. 결과는 최대 `민감정보 가능성 높음(건강 사항 포함)`처럼 짧게 표시합니다. 원래 선택 목록의 알려진 항목은 로컬 유형 분류를 사용합니다. [분류 API 설정](privacy-classification.md)을 참고하세요.

## 2단계

개인정보·목적 외 이용·제3자 제공·마케팅을 탭 없이 한 화면에서 확인합니다. 각 처리 유형 안에 일반 개인정보(필수)·일반 개인정보(선택)·민감정보·고유식별정보 영역을 표시합니다. 항목 아래 분류 문구와 필수/선택 스위치를 반복하지 않습니다.

손잡이를 끌어 같은 처리 유형 안에서 분류를 바꿉니다. 다른 처리 유형으로의 이동은 허용하지 않습니다. 키보드로는 손잡이에 포커스를 두고 좌우 화살표로 분류를 바꾸고, 위아래 화살표로 같은 분류 안의 순서를 바꿀 수 있습니다. 터치 기기에서는 손잡이를 누른 채 이동합니다.

## 3단계

법령 자동 검색 결과는 선택한 항 전체와 하위 호·목을 표시하고 선택한 호를 강조합니다. 공식 원문의 호 번호를 사용하므로 같은 문구가 다른 호에 있어도 구분합니다. 조·항·호 칸은 모바일에서도 한 줄로 표시하며, 선택한 조는 짧은 번호로 표시하고 목록 안에서는 조 제목을 보여줍니다. 없는 항·호는 회색 비활성화합니다.

‘전체선택’과 항목 체크박스를 같은 위치에 맞췄습니다. 공통 요건 확인란은 AI가 찾은 근거에 표시하고 직접 등록에서는 생략합니다. 구체적인 법령상 처리 권한과 주민등록번호의 특별 요건 확인은 필요한 경우 유지합니다.

## 4단계와 저장

같은 구분의 표와 중복 셀을 합치며 고지 항목도 포함합니다. 동의·고지가 같은 표에 있으면 처리 방식으로 구분하고 동의 대상 항목명만 동의 질문에 표시합니다. [표 통합 안내](grouped-documents.md)를 참고하세요.

문서 수정 요청 기능은 제거했습니다. 완성 버튼은 미리보기 위·아래에 표시합니다. 고지사항만 있으면 동의 거부 입력란 대신 `동의를 받아 개인정보를 수집하지 않기 때문에 해당사항 없습니다.`를 회색으로 표시합니다. 안내문 후보도 별도의 동의를 받지 않는 고지사항에 맞게 제공합니다.

기관 귀중 문구를 크게 표시합니다. 한글(HWPX) 동의·미동의 줄은 테두리 없는 2열 표로 만들며 왼쪽 설명은 왼쪽, 선택란은 오른쪽 정렬합니다.

## 실행·검증

기존 `.env`를 새 폴더의 `server.py` 옆으로 복사하고 서버를 재시작한 다음 Ctrl+F5로 새로고침하세요. `/api/status`의 `apiVersion`은 **7**입니다.

서버 테스트와 근거 규칙 테스트, Playwright의 법령 흐름·민감정보 분류·문서 통합·화면 조작 검증을 수행합니다. 별도 화면 조작 검증은 다음 명령으로 실행합니다.

```sh
TEST_BASE_URL=http://127.0.0.1:3008 node tests/workflow-layout.cjs
```

브라우저 API 응답은 합성 데이터입니다. 실제 API 인증·판단 정확도를 입증하지 않습니다. 한글 저장은 XML 구조에서 테두리 없음·좌우 정렬·글자 크기를 확인했으며 실제 한글 프로그램의 렌더링을 이 환경에서 확인한 것은 아닙니다.

화면 조작 검증은 마우스 드래그, 키보드 이동 및 터치 입력을 검사합니다. 파일 내보내기 검증 후 `python tests/check_exports.py`를 실행하면 한글 표 구조와 PDF 텍스트 중복·누락을 확인할 수 있습니다.
