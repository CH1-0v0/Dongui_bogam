# 1·2단계 민감정보 분류

1단계에 입력하는 것은 실제 개인정보 값이 아닌 ‘건강정보’, ‘상담 기록’ 등의 **항목명**입니다.

- 법령에 명시된 유형을 나타내는 항목명(건강정보, 사상·신념, 성생활, 정치적 견해, 범죄경력, 생체인식정보, 인종·민족 등)은 **민감정보**로 표시합니다. 고유식별정보는 별도로 구분합니다.
- 직접 입력한 항목 중 추가 검토가 필요한 경우에만 서버 API가 개인정보 보호법 제23조와 같은 법 시행령 제18조의 공식 원문을 확인한 후 AI로 검토합니다. 높은 가능성으로 판단된 항목은 **민감정보 가능성 높음**으로 표시합니다. 표시는 최대 `민감정보 가능성 높음(건강 사항 포함)`처럼 짧게 제한합니다. 긴 검토 이유·숫자 확률·모델 정보는 화면에 표시하지 않습니다.
- 높은 가능성으로 판단된 항목은 2단계에서 **민감정보**로 우선 분류합니다. 담당자는 일반 개인정보로 변경할 수 있습니다. 담당자가 변경한 분류를 늦은 API 응답으로 덮어쓰지 않습니다.
- API가 실패하거나 맥락이 부족하면 ‘가능성 미확인’ 또는 ‘가능성 확인 필요’로 표시합니다. 실패를 ‘높은 가능성’으로 표시하지 않습니다. 로컬 규칙상 건강·상담 등으로 추가 확인이 필요한 항목은 API 미확인 상태에도 보수적으로 민감정보를 기본 제안하며, 담당자가 변경할 수 있습니다.

현재 법령상 유형의 로컬 매칭은 항목명 사전이며 모든 표현과 업무를 포괄하는 법률 판단이 아닙니다. 예를 들어 일반 사진을 모두 생체인식정보로 단정하거나 모든 상담을 민감정보로 단정하지 않습니다. 실제 항목의 의미와 처리 방식을 담당자가 확인해야 합니다.

## 실행과 키

`.env`를 `server.py`와 같은 폴더에 두고 다음 서버 전용 값을 설정합니다. 값은 브라우저 파일에 넣지 않습니다.

```dotenv
LAW_API_OC=승인받은_OC
OPENROUTER_API_KEY=발급받은_키
OPENROUTER_MODEL=openai/gpt-oss-120b
```

기존 서버를 Ctrl+C로 종료하고 새 폴더에서 `python server.py`를 실행합니다. `http://127.0.0.1:3000`에서 Ctrl+F5로 새로고침합니다. `/api/status`의 `apiVersion`은 **7**입니다. 설정 여부는 인증 성공을 의미하지 않습니다.

## 호출 방식

새 API는 같은 출처의 `POST /api/privacy/classify`입니다. 직접 입력한 항목 id·항목명·입력된 이용 목적을 서버로 보내고 공식 기준 조문을 AI에 함께 제공합니다. 알려진 일반 항목과 명시적 민감정보·고유식별정보는 로컬에서 먼저 구분합니다. 직접 입력으로 추가한 알 수 없는 항목만 입력이 멈춘 뒤 1.2초 후 묶어서 요청하며 한 번에 최대 20개입니다. 항목명·목적이 같으면 결과를 재사용하고, 변경·삭제·새 문서의 응답은 무효화합니다.

1단계에서 다음 단계로 이동할 때 진행 중인 분류를 확인하고 이동합니다. 외부 API가 응답하지 않으면 제한 시간 후 확인 실패로 표시하고 이동할 수 있습니다. 실패 후 ‘다시 확인’으로 재시도할 수 있습니다. 민감정보 분류·근거 검색·직접 추가한 법령의 AI 검토는 프로세스당 분당 6회 AI 호출 한도를 공유합니다. 분류에도 모델 사용료가 발생할 수 있습니다. 공식 조문은 서버 캐시를 재사용합니다.

외부 API에서 시간 초과로 종료된 요청도 제공자가 이미 처리했다면 비용이 발생할 수 있습니다. 실제 지연·가격·판단 정확도는 현재 환경에서 측정하지 않았습니다.

## 테스트

기존 안내의 서버·법률 규칙·브라우저 테스트에 더해, Playwright와 Chromium이 설치된 검증 환경에서:

```sh
TEST_BASE_URL=http://127.0.0.1:3007 node tests/classification-browser.cjs
```

합성 응답으로 법정 유형 표시, 높은 가능성 표시, 2단계 민감정보 기본 분류, 수동 변경 유지, 실패·재시도, 이름 변경 중 늦은 응답 무효화와 응답 문자열의 HTML 이스케이프를 확인합니다.

실제 API 인증과 연동을 확인하려면 프로젝트 폴더에서:

```sh
python tests/live_api.py --classify
```

이 명령은 공식 법령 조회와 민감정보 AI 분류를 실제로 호출하므로 모델 사용료가 발생할 수 있습니다. 실제 응답이 ‘일반’·‘확인 필요’이면 해당 의견 그대로 표시하며 테스트가 민감정보 확정 판단을 보증하지 않습니다.
