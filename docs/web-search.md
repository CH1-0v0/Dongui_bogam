# OpenRouter 웹 검색으로 법령 근거 찾기

추가 패키지 설치나 Exa 키 없이 기존 OPENROUTER_API_KEY를 사용합니다. 법령 원문 조회에는 기존 LAW_API_OC가 필요합니다. 이번 통합은 최신 main의 법령 캐시·시행규칙 종류 인식·검색 상태 안내를 유지합니다. 직접 법령 등록의 본문 키워드 검색은 제공하지 않습니다.

## 처리 순서

1. 항목명·처리 목적·정보 유형을 Responses API `/api/v1/responses`에 전달합니다.
2. `tools`에 `openrouter:web_search`를 등록합니다. Exa 엔진으로 법령정보센터·국세청·보건복지부·개인정보보호위원회 등의 공식 사이트를 검색하도록 요청합니다.
3. 응답의 실제 `url_citation` 주석에서 허용된 공식 도메인 출처를 수집합니다. 검색 보고서와 출처가 없거나 응답이 미완료이면 후보 생성을 중단합니다. 기억 기반 검색으로 자동 대체하지 않습니다.
4. 기존 Chat Completions 요청에 검색 자료를 제공해 법령·조문 후보를 구조화합니다. 형식 오류에는 최대 한 번 재시도합니다.
5. 국가법령정보센터에서 현행 법령과 구체 조문, 개인정보 보호법 연결 근거를 확인합니다. 개별 법령 요청 제한은 30초입니다.
6. 원문과 업무·항목을 다시 대조합니다. 모두 not_supported인 후보는 제외합니다. 정보 부족 항목은 자동 추천하지 않고 확인 사항을 표시합니다.
7. 화면의 ‘웹 검색 참고 출처’에 탐색 단계 출처를 표시합니다. 각 후보의 현행 법령 원문 링크와는 구분합니다. 탐색 출처 목록이 모든 후보에 대한 직접 인용 대응표라는 뜻은 아닙니다.

검색은 관련 발췌와 AI 보고서를 반환합니다. 모든 출처 페이지의 전문을 별도로 내려받아 읽었다고 표시하지 않습니다. 최종 법적 근거는 공식 법령 API 원문으로 확인합니다. 정확한 조문과 업무 적용 여부에 대한 담당자 검토는 필요합니다.

## 비용·제한·설정

공통 설정은 cloudflare/web-search.json에 있습니다. 모델은 기존 OPENROUTER_MODEL을 유지합니다. 검색 엔진은 도메인 필터와 사용량 제한이 적용되는 exa로 지정했습니다. 검색 호출 최대 3회, 호출당 결과 5건, 총 결과 15건, 결과당 발췌 최대 4,000자이며 검색 단계 대기 제한은 90초입니다. 검색 단계는 자동 반복하지 않습니다. 후보 구조화 재시도에는 같은 검색 자료를 재사용합니다. 검색·모델 생성·후보별 검토 비용은 별도로 발생합니다.

서버 도구는 OpenRouter의 베타 기능입니다. 계정 권한·검색 엔진 설정·모델 제공자 지원에 따라 사용할 수 없을 수 있습니다. 제한이 걸리면 계정 설정을 확인해야 하며 도구나 데이터 수집 거부 설정을 제거하는 방식으로 우회하지 않습니다. 입력한 업무 맥락과 항목명은 OpenRouter 및 검색 처리에 사용되므로 실제 개인의 식별값을 입력하지 마세요.

Python 서버는 설정 JSON을 직접 읽으므로 cloudflare 폴더도 함께 보관하세요. Cloudflare는 기존 `npm ci`, `npm run build`, `npm run deploy` 절차로 모듈과 설정을 묶습니다. 새 Secret은 필요하지 않습니다. GitHub 소스 반영과 운영 Worker 배포는 별개입니다.

## 검증

`npm run test:cloudflare`와 `python -m unittest discover -s tests -p test_server.py`는 합성 검색·법령 데이터로 통합 순서, 출처 검증, 오류·캐시·업무 관련성 처리를 확인합니다. `tests/worker-runtime.cjs`는 실제 workerd의 fetch로 Responses API 요청 형식을 검증하되 외부 응답은 합성 데이터입니다. `tests/browser.cjs`는 참고 출처의 안전한 표시와 기존 직접 등록·내보내기를 확인합니다.

본인의 키로 실제 검색 품질을 확인하려면 `python tests/live_api.py --search`를 실행하거나 강사료·자문료·진료 사례를 화면에서 비교하세요. 이 명령은 여러 유료 API 호출을 실행할 수 있습니다. 자동 테스트 통과는 실제 API 인증이나 법률 검색 정답률을 입증하지 않습니다.
