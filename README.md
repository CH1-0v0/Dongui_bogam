# 개인정보 문서 작성실

개인정보 항목을 분류하고 동의서·고지서를 작성하는 웹 앱입니다. 3단계에서 개인정보 유형별 법령을 검토하고 항목별로 적용합니다. 개인정보 보호법 근거를 먼저 선택하고, 필요한 경우 개별 법률·시행령을 선택합니다. 법령은 + / −로 접고 펼치며 선택 안함 후에도 다시 확인할 수 있습니다. AI가 찾은 법령에는 추가 AI 검토를 표시하지 않습니다. 직접 추가한 법령의 AI 검토는 선택사항이며 부정적인 의견이어도 담당자가 원문과 요건을 확인한 후 적용할 수 있습니다. 하나를 선택하면 같은 유형의 다른 미선택 법령을 숨깁니다. 직접 추가에서는 선택 항목을 제외합니다. 검색은 전체 건수를 별도 집계하고 최대 5행의 목록에서 스크롤로 추가 조회합니다. 행정규칙은 체크한 경우 참고자료로 조회합니다.

Python 3.12 이상이면 별도 서버 패키지 설치가 필요 없습니다.

```sh
python3 server.py
```

로컬 컴퓨터에서 실행했다면 브라우저에서 `http://127.0.0.1:3000`을 엽니다. API를 쓰려면 먼저 [키 보관·배포·테스트 안내](docs/step3-api.md)를 따라 `.env`를 설정하세요. Python의 `http.server`만 실행하면 API 기능은 동작하지 않습니다.

키 없이 화면만 확인하려면 다음처럼 명시적으로 시연 모드를 켭니다.

```sh
LAW_SEARCH_DEMO=true python3 server.py
```

홈의 **예시로 시작 → 다음 단계 → 분류 확정 후 다음 → 검색 방식: 화면 시연** 순서로 확인합니다. 시연 결과는 실제 API 검증으로 표시되지 않으며 고지 전환의 근거가 되지 않습니다.

```sh
node --test tests/basis.test.cjs
python3 -m unittest discover -s tests -p 'test_*.py' -v
```

UI와 PDF·HWPX 회귀 검증은 Playwright와 Chromium이 설치된 개발 환경에서 서버를 실행한 뒤 `node tests/browser.cjs`로 실행합니다. 이 저장소에는 Playwright를 애플리케이션 의존성으로 추가하지 않았습니다. 설치 방법과 실제 API 검증 명령은 위 안내에 있습니다.

1단계는 법령에 명시된 민감정보와 API 검토상 민감정보일 가능성이 높은 항목을 구분합니다. 가능성이 높은 항목은 2단계에서 우선 민감정보로 분류하고 담당자가 변경할 수 있습니다. [분류 방식과 실제 API 테스트](docs/privacy-classification.md)를 참고하세요.

최근 화면 정리: 직접 입력 항목의 짧은 민감정보 가능성 표시, 항 전체 원문과 선택 호 강조, 한 줄 조·항·호 선택, 같은 개인정보 구분의 표·공통 셀 통합을 제공합니다. [표 통합과 검증 안내](docs/grouped-documents.md)를 참고하세요.

입력·분류 화면은 짧은 스크롤 선택창과 드래그 이동을 제공합니다. 2단계는 모든 처리 유형을 펼쳐 표시하며, 4단계는 상·하단 완성 버튼과 고지사항 전용 안내를 제공합니다. [전체 화면 변경 안내](docs/editor-flow.md)를 참고하세요.

첨부 안내서 반영: 처리 상황별 법령 등록, 주민등록번호 동의 제외, 동의와 하단 고지 분리, 표 편집·저장, 동의 구분별 최종 체크, 제목 기반 파일 저장을 제공합니다. [안내서 반영 기준과 검증](docs/guideline-application.md)을 참고하세요.
